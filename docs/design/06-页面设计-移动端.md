### 6.1.1 通用页面骨架（二级及以下页面）

```
┌────────────────────────────────────────────┐
│  9:41                            ▂▄▆ ᯤ ▮  │  状态栏（透明，edge-to-edge）
│                                            │
│  ‹            页面标题              ✓      │  手写 Row：50×44 / 18 w600 居中 / 50×44
│                                            │  ← 零高度 AppBar 只用于设状态栏样式

│  │  …Card（fromLTRB(20,0,20,0) 内边距） │  │  ← 内容区 fromLTRB(20,15,20,0)
│  └──────────────────────────────────────┘  │
│                                            │
└────────────────────────────────────────────┘
```

| 层 | 规格 |
|---|---|
| `Scaffold.appBar` | `PreferredSize(preferredSize: Size.zero, child: AppBar(systemOverlayStyle: ...))` |
| `body` | `SafeArea` → `Padding(fromLTRB(0,20,0,0))` → `Column` |
| 标题栏 | `Row(spaceBetween)`：`SizedBox(50,44)` + `Icon(arrow_back_ios_outlined, 26)` ｜ `Text(18/w600, center, ellipsis)` ｜ `SizedBox(50,44)` + 动作 |
| 间隔 | `SizedBox(height: 10)` |
| 内容 | `Expanded` → `Padding(fromLTRB(20,15,20,0))` → `SingleChildScrollView` / `Scrollbar`+`ListView` |
| 区块 | `Card`（色 `#303030`/`#FFF`，elevation 1，r12，`margin all(4)`）→ `Padding(fromLTRB(20,0,20,0))` → `ListView.separated` |
| 分隔 | **`const Divider(height: 1, thickness: 0.3)`** |
| 状态管理 | 继承 `LasyRenderingStatefulWidget`（非当前路由/后台时延迟重绘） |

| 属性 | 值 | 说明 |
|---|---|---|
| 高度 | **56** | 不是 M3 的 80 |
| 背景 | `colorScheme.surface`（深 `#121212` / 浅 `#F0F0F0`） | 与页面同底，不浮起 |

| 涟漪 | 整格 `InkWell` | — |

### 6.1.5 切换与返回行为

| 场景 | 行为 |
|---|---|
| 点 Tab | `IndexedStack` 切 index；**不重建状态** |
| 再点当前 Tab | 该 Tab 的 `Navigator.popUntil(isFirst)` |
| Android 返回键 | 当前 Tab 栈非根 → `pop`；根且非 Tab 0 → 切 Tab 0；根且 Tab 0 → `MoveToBackgroundUtils.moveToBackground()` |
| 跨 Tab 跳转 | T-0 账户状态条 → `setTab(2)`；T-3「套餐与续费」→ `setTab(2)` |
| 非当前 Tab 重绘 | `LasyRenderingState` 延迟重绘 |
| 会话失效 | 清全部 Tab 栈 + 清 token + 清订阅缓存 → `M-01` |

```

┌── 错误态（AlertDialog）───────────────────┐
│  提示                                       │

┌── 加载态 ≠ 错误态（T-0 主页）─────────────┐
```

> Mclash 保留这一克制 —— 唯一例外是 T-0 的账户状态条在「未开通套餐」时显示一行可点击提示。
