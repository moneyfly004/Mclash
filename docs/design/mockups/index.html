Mclash · 设计稿总览 v3.0

Clash Mi 的界面与全部代理能力 + MoneyFly 的账号与商业化闭环。 视觉、排版、组件 100% 沿用 Clash Mi（Material 3 + 种子色 #293CA0 + 方角 + 高密度列表 + 唯一分隔线 Divider(1, 0.3) + SimpleDialog 全家桶 + platform: TargetPlatform.iOS）； 导航层按需新增 4 个底部 Tab；Clash Mi 的代理管理 / 分流 / 内核设置 / 应用设置 / 备份同步 / 网络检测等能力 一个不少（仅移除 zashboard 面板与二维码工具 2 项）。

North Star Flow · 用户只做两件事

1安装并打开→ 2登录 MoneyFly 账号→ 自动：拉订阅 → 解析节点 → 写入「我的配置」→ 并发测速 → 选中最优 → 3拨动首页连接开关
目标：从安装到上网只需 2 次操作；登录 → 节点可用 ≤ 5s；拨开关 → 已连接 ≤ 3s。 但进阶用户要用 Clash Mi 的 DNS / TUN / 分流 / 规则 / 代理组 / 网络检测时，一个功能都不缺。
